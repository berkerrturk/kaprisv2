# İlk Sprint

## Amaç

Kodlamadan önce MVP'nin sınırlarını ve ilk veri modelini kesinleştirmek; ardından çalışır bir ürün kataloğu iskeleti kurmak.

## Görevler

- [x] MVP kategorilerini seç
- [ ] Her kategori için filtre/özellik listesini çıkar
- [x] Örnek 20–50 ürünü standart forma dönüştür (Goldium'dan 48 minimal yüzük; stok ve fiyat canlı değil)
- [x] Satış mı talep toplama mı kararını ver: sitede satın alma; seçenekler yeterli değilse ürün tarifiyle talep
- [ ] Teknoloji alternatiflerini değerlendir ve karar kaydı oluştur
- [ ] Veri tabanı şemasını tasarla
- [ ] Ana sayfa, soru akışı, sonuç ve ürün detayı wireframe'lerini hazırla
- [x] Proje iskeletini oluştur
- [x] Test, lint ve format kontrollerini kur
- [x] Örnek verilerle ilk dikey akışı çalıştır (kategori → filtre → sonuç → Kapris ürün detayı)

## Sprint çıktısı

Kategori seçimi → sorular → örnek sonuçlar → ürün detayı akışı yerel ortamda çalışmalıdır.
